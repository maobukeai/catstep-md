# Keyboard Shortcuts ⌨️

> Note: Use `Ctrl` on Windows & Linux, and `Cmd` (`⌘`) on macOS. Catstep MD provides full Typora-grade shortcut parity.

---

## Headings & Formatting (Typora Core)

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Ctrl+1` ~ `Ctrl+6` | Headings 1 ~ 6 (H1 ~ H6) | Convert the current line to the corresponding heading level |
| `Ctrl+0` | Normal Paragraph | Convert current heading/block back to standard paragraph text |
| `Ctrl+=` / `Ctrl+-` | Promote / Demote Heading | Increase or decrease the heading level (e.g. H2 ➔ H1) |
| `Ctrl+B` | **Bold** | Surround selected text with double asterisks |
| `Ctrl+I` | *Italic* | Surround selected text with single asterisks |
| `Ctrl+U` | <u>Underline</u> | Insert HTML underline tags |
| `Ctrl+Shift+X` / `Alt+Shift+5` | ~~Strikethrough~~ | Add tilde strikethrough styling |
| `Ctrl+Shift+` ` | `Inline Code` | Wrap selection in backticks |
| `Ctrl+K` | Insert Link | Convert selected text to a hyperlink |
| `Ctrl+Shift+I` | Insert Image | Trigger image insertion dialog |
| `Ctrl+\` | Clear Formatting | Remove all Markdown formatting marks from selection |

## Blocks & Tables

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Ctrl+T` | **Insert Table** | Create a table with in-place floating toolbar |
| `Tab` / `Shift+Tab` | Next / Previous Cell | Navigate table cells; pressing Tab in last cell appends a row |
| `Ctrl+Shift+K` | Insert Code Block | Insert triple-backtick code block with syntax highlighting |
| `Ctrl+Shift+M` | Insert Math Block | Insert KaTeX `$$ ... $$` block with live preview |
| `Ctrl+Shift+Q` | Blockquote | Prepend `> ` to the current line |
| `Ctrl+Shift+[`, `Ctrl+Shift+]` | Ordered / Bullet List | Toggle numbered or bulleted list styling |
| `Ctrl+Shift+Backspace` | Delete Line | Delete current line or table row instantly |

## Views & Modes

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| **`Ctrl+/`** | **Toggle Live / Source Mode** | **Typora's signature shortcut** — switch between Live Preview & raw code |
| `Ctrl+Shift+L` | **Toggle Sidebar** | Expand or collapse left drawer (Files, Outline, Search) |
| `Ctrl+Shift+1` | Outline View | Open document outline navigation |
| `Ctrl+Shift+2` | File Tree View | Open workspace file tree |
| `Ctrl+Shift+3` | Global Search | Search notes across the workspace |
| `F8` | Focus Mode | Dim surrounding paragraphs to focus on current line |
| `F9` | Typewriter Mode | Keep active typing cursor centered vertically on screen |
| `F11` | Fullscreen | Distraction-free full-screen writing canvas |

## File & Application

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Ctrl+N` | New Markdown File | Create an untitled tab in the current window |
| `Ctrl+Alt+N` | New Plain Text File | Create a `.txt` note |
| `Ctrl+Shift+N` | New Window | Open an independent editor window |
| `Ctrl+O` | Open File… | Open system file picker |
| `Ctrl+S` | Save | Save current note to disk |
| `Ctrl+Shift+S` | Save As… | Save copy to a new path |
| `Ctrl+W` | Close Tab | Close active note tab |
| `Ctrl+Shift+T` | Reopen Closed Tab | Restore accidentally closed note |
| `Ctrl+P` | **Quick Switcher** | Fuzzy search notes by filename across your vault |
| `Ctrl+Shift+P` | **Command Palette** | Search and execute all application commands |
| `Ctrl+,` | **Preferences** | Open Settings modal (themes, fonts, shortcuts, about) |
| `Ctrl+Alt+0` | Reset Zoom | Reset UI zoom scale to 100% |

## Catstep Superpowers

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Ctrl+J` / `Ctrl+Shift+A` | **✨ Catstep AI Assistant** | Toggle right AI drawer for polishing, summarizing, and Q&A |
| `Ctrl+Shift+H` | **⏱️ Version Time-Machine** | Inspect AutoGit snapshot diffs and roll back versions |
| `Ctrl+Alt+P` | **Slideshow Presentation** | Present the active Markdown document as fullscreen slides |
| `F1` / `Ctrl+Shift+?` | Markdown Help | Open reference guides and cheat-sheet |

> 💡 **Custom Keybindings**: Open `Settings (Ctrl+,) ➔ Shortcuts` to customize any keybinding by clicking "Change" and pressing your preferred chord.
