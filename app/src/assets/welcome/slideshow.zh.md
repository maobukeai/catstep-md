# 投影演讲模式 — 优雅极简的全屏幻灯片 🚀

猫步 MD 能把任意 Markdown 文档秒级化身为 **全屏演讲幻灯片** —— 告别繁杂的 PPT 排版，无需导出或安装任何额外演示软件，专注表达与内容本身。

---

## 一、 怎样开始放映

- **快捷键触发**：按 **`Ctrl+Alt+P`**（macOS 上按 **`Cmd+Alt+P`**），当前文档即刻在新全屏放映窗口中呈现。
- **命令面板触发**：按 **`Ctrl+Shift+P`** 呼出全局命令面板，输入 **"开始幻灯片演示" (Present Slideshow)** 即可一键启动。

---

## 二、 幻灯片分页规则

只需在段落之间使用单独一行的三个连字符 **`---`** 作为分页符：

```markdown
# 第一页：灵感起源

极简轻量，让打字成为一种享受。

---

# 第二页：核心架构

- Tauri 2 + Rust 本地高性能内核
- 全键位 Typora 深度兼容
- 实时编辑、就地表格与猫步 AI

---

# 第三页：完美成稿

让每一次书写都步步轻盈。
```

> 💡 **智能识别**：文档最开头的 YAML Front Matter（`--- ... ---`）会被智能解析跳过，不会被误当成空白幻灯片。

---

## 三、 放映导航快捷键

| 按键 | 动作效果 |
| :--- | :--- |
| `→` / `↓` / `空格` / `PageDown` | 切换下一页幻灯片 |
| `←` / `↑` / `PageUp` | 返回上一页幻灯片 |
| `Home` / `End` | 直达首页 / 末页 |
| `F` | 切换全屏 / 窗口化放映 |
| `?` | 呼出放映快捷键帮助卡片 |
| `Esc` | 退出放映，返回编辑器 |
| 鼠标单击屏幕 | 切换下一页 |
| Vim 键位支持 | 支持 `h` `j` `k` `l` 无缝翻页 |

---

## 四、 丰富内容渲染支持

幻灯片放映完全继承猫步 MD 的全套渲染能力：高亮代码块、KaTeX 数学公式、就地表格、警示呼出块、任务清单以及 Mermaid 流程图均原生呈现！

```mermaid
flowchart LR
  A[✍️ 构思大纲] --> B[🐾 猫步 MD 编辑]
  B --> C[⌨️ 按 Ctrl+Alt+P]
  C --> D[🚀 全屏震撼放映]
```

---

## 五、 演讲与排版技巧

- **大标题精炼**：每页使用单一 `# 标题` 搭配 2~4 行精要论述，大屏幕呈现视觉最通透。
- **字号自适应缩放**：放映引擎会根据屏幕与投影仪分辨率自动等比例缩放字体，保证清晰可读。
- **代码展示建议**：每页展示核心关键代码，超长代码建议按功能拆分为连续的多页。
- **多屏演说建议**：主屏全屏放映，副屏保留猫步 MD 源码作为演说提词备注。
